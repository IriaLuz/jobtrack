# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## About the project

**jobtrack** is a job application tracker web app. It is a learning project — the goal is for the developer to grow into senior full-stack, starting from a React background and learning backend development along the way.

## About me

I'm a React developer learning backend development and working towards senior full-stack. I am using this project to LEARN.

## How to work with me

- Explain the *why*, not just the fix. Use frontend analogies where helpful.
- When reviewing my code, point out problems and ask guiding questions — let me attempt the fix myself first.
- When I'm stuck, give me a hint before a solution. Escalate to the full answer only if I ask for it explicitly.
- Prefer small incremental changes over large rewrites.
- Never write whole features for me unless I explicitly say "implementation mode".
- After we solve any bug together, finish with a short recap: root cause, how we found it, and how I can recognise it next time.
